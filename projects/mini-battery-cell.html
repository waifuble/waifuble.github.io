Mini Battery Cell Production

🔋

This project simulates the manufacturing process of a battery cell, focusing on the precision required for "jellyroll" winding. The system aims to replicate industrial standards by wrapping copper coils around a cylindrical base to act as an anode and cathode. By monitoring linear web speed and environmental conditions, the project determines the quality of each cell, using a diverter mechanism to sort them into "PASS" or "FAIL" categories based on uniform layering and manufacturing constraints.

The system centers around an ESP32 microcontroller acting as the primary logic controller, managing both sensor inputs and mechanical outputs.

Logic & Calculation Framework

The project's success relies on maintaining a uniform membrane layer through the calculation of linear web speed and environmental stability. If the linear web speed is too high, spillage can occur during the windage process. Both processes act as quality check processes. The variables utilized from the Thermo modules are T & rH, and from the Modulino is the dps.

Quality Metric 1: Linear Web Speed

To ensure the membrane is not wrapped too tightly or loosely, the system calculates the speed relative to the increasing diameter of the coil:

\[ LWS = \frac{dps \cdot \pi \cdot D}{360} \]

If the calculated speed deviates from the target V_target, or if the tension becomes non-uniform, the cell is flagged.

Quality Metric 2: Environmental Check

The system uses the Modulino sensor to monitor Relative Humidity (RH). High humidity can compromise the integrity of the materials or the "checks" during the winding process.

\[ Tdew = T - \frac{100 - rH}{5} \] \[ \text{IF } (V_{web} \approx V_{target}) \text{ AND } (RH < RH_{max}) : \text{PASS (Servo actuates to "Success" lane)} \] \[ \text{IF } (V_{web} \neq V_{target}) \text{ OR } (RH \ge RH_{max}) : \text{FAIL (Servo actuates to "Diverter" lane)} \]
