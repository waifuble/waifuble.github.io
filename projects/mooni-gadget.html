Muse AI Gadget Assistant — Mooni

🌙

This project is my attempt at building a physical AI assistant: a physical Mooni. Mooni is my everyday agent from Meta's Muse. The idea is simple: take the Muse gadget SDK, put it on an Arduino Uno Q with an LCD, and give him a face and a voice on my desk. Hosted on the Uno Q to integrate ephemeris

The Uno Q is really two computers in one: a Qualcomm QRB2210 running full Debian Linux, and an STM32U585 running Zephyr for real-time I/O. Python on the Linux side talks to Arduino code through Bridge. The Muse gadget SDK installs on the Debian side and gives four powers: run shell commands, read files, write files, and check device health.

The Logic & Calculation Framework

Two layers:

Almanac (no Mooni needed). All the sky math runs on the Uno Q itself — a Python ephemeris computing positions, transits, and moon phases. Works offline, forever, no pairing, no internet. That's the reliable core, and it's a complete device on its own.

Brandon Rhodes' ephem library is the engine behind the almanac layer.

Mooni (Muse SDK). The conversation. Positions go up through the gadget pairing, get interpreted, and come back out the LCD and speaker. The magic layer.

Build Status

🛠

Where things stand: the SDK requirements are verified against the Uno Q line by line (Debian 11+, 64-bit ARM, BLE 5.1, sudo account) and the install steps are confirmed — SSH in, run the installer with an SDK token from gadgets.muse.ai, pair as MuseGadgetXXXXXX in the app with Developer mode on. The Mooni figurine STL is modeled and hollowed.
